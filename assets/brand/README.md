# Rulora brand assets

- `rulora-logo.png`：Image 生成的高分辨率主图标；
- `rulora-logo-512.png`：GitHub 头像与社交预览备用尺寸；
- `rulora-logo-256.png`：README 展示尺寸。
- `rulora-social-preview.png`：GitHub 分享卡片，1280×640。
- `rulora-social-preview.svg`：分享卡片可编辑源文件。

该图标以权利人提供的“通关文牒”Logo 为品牌母体进行授权改造，表达 Rulora 的 Hybrid
机制：青色有机路径代表模型的理解与生成，琥珀色几何路径代表程序规则，两者在中心汇合。

Logo 不随 Apache-2.0 代码许可证自动授权修改或用于混淆性品牌用途，具体规则见根目录
`TRADEMARKS.md`。
