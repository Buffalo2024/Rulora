# 能保证什么，不能保证什么

| 层次 | 已实现的约束 | 不应推导出的保证 |
| --- | --- | --- |
| OutputBoundary | 按序运行验证器；非 true 拒绝 | 自动发现谎言、自动防止 Adapter 改结论 |
| LoopControl | 分类计数、停止状态 | 自动调度、全局成本上限、强制取消在途请求 |
| CollectiveControl | JSON 快照递归冻结、池归属、合法 ID 选择 | 独立来源、业务共识、选出最优答案 |
| 工作流状态机 | 字段、分支、回合证据和恢复不变量 | 数据库事务、外部动作 exactly-once |
| 群体决策 | 两层五席、有界交换、候选绑定、调用检查点 | 决策准确性、模型无偏、可直接公网部署 |

## 复现的含义

相同输入与环境下的程序结果可测试；已通过校验的调用结果可按匹配条件复用。
重新请求概率模型不承诺输出逐字相同。
检查点写入前进程崩溃，外部请求可能已经发生；副作用需要宿主的幂等键或事务机制。

## 安全边界

这些组件运行于受信任宿主，不是执行恶意 JavaScript 的隔离沙箱。
本地场景页面不具备完整公网认证、租户隔离与授权。显示掩码不等于服务端脱敏。
日志、证据和检查点可能包含完整输入；不得随仓库或 npm 包发布。

测试、静态隐私检查和 npm audit 只覆盖各自范围，不能替代独立安全审计。
