# 运行修订审查与开源迁移

## 2026-10-13 后续迁移

补充调度器部分更新语义、排队请求取消、资源/主动取消错误不计入供应商熔断。

## 结论

应用修订加强了错误定位、复核约束和供应商传输兼容，但不是可直接复制的通用发行版。
开源迁移选择性保留可复用机制，不将生产连通回执解释成完整业务验收或准确性证据。

| 审查发现 | 公开处理 |
| --- | --- |
| 长推理存活探测，但端点可达时可能无限等候 | 可选接入，增加有限等待与响应大小预算、取消支持 |
| SSE 中途断开及流式错误 | 拒绝半截输出，有限重试，完成标记后不再拼接 |
| system 消息顺序不兼容 | 纯传输适配，保留用户/证据/工具内容，拒绝有损合并 |
| Adapter 混入业务复核提示 | 业务合同留在 Prompt，传输 Adapter 不增加判断规则 |
| 单项分类错误被迫使用多项冲突结构 | 增加独立问题类型与严格行动绑定 |
| 比较原因字段缺失反馈笼统 | 精确字段定位，区分格式问题与业务重新复核 |
| 格式修订只比较缺口是否非空 | 同时冻结既有缺口内容，防止替换问题原文 |
| 额外格式修订容易混为无界重试 | 显式分类与次数上限，旧合法裁决不得漂移 |
| 并发调整与生产无限并发混合 | 仅迁入动态有限上限，保持保守默认值 |
| 真实任务、私有部署和历史样例散落 | 白名单迁移代码；新增回归全部使用合成输入 |

## 留在应用层的内容

供应商专属版本菜单、模型岗位分配、私有来源、共享云设置、检索召回扩展及生产维护脚本不进入 Core。
本轮不复制页面或新增公网接口。源修订的真实 API 连通记录未经本轮独立复测，不能作为公开验证结果。
推理内容转最终答案的供应商专属回退暂不通用化；不能仅因正文为空就接受任意思考片段。

## 可复现验证与限制

主仓库 `npm run verify:local` 统一验证 Core、类型、示例、完整群体重放、网页冒烟、隐私、文档及打包。
新增测试覆盖慢响应、健康但卡住的请求、探测失败、永不返回的探测、取消、断流、响应过大、
终止后的多余内容、消息适配纯度、问题绑定、裁决漂移与动态并发。
输入均为合成内容，未向真实供应商发送应用数据。

必须继续由宿主负责认证、租户隔离、预算、日志保留与实际业务人工审核。
原始不可解析 JSON 的业务语义不能通过程序完全证明，修订后门禁不等于事实正确。
没有在本轮执行真实 Provider、生产 PostgreSQL 或生产任务重启验证。
