未合入供应商专属适配、真实业务数据、生产配置、云端共享偏好或私有热更新脚本。

## 复现与限制

仓库根目录：`npm run verify:local`。

案例目录可单独运行：

```sh
node --test tests/network-socket-recovery.test.js tests/storage-portability.test.js
```

本地测试需允许监听临时回环端口，不需要真实模型 API Key。
未调用真实商业模型，未验证企业决策准确率、生产数据库或生产任务热更新。
本地复用已安装依赖，空缓存安装和其他操作系统仍需 CI 验证。
隐私规则扫描不等于完整安全审计；宿主仍负责认证、租户隔离和日志保留。
存活监测模式的请求取消不应被描述成完整网页任务暂停。
