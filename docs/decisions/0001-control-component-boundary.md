# ADR 0001：保持控制组件与业务合同分离

状态：采用。

## 问题

用户需要将输出门禁、循环预算和候选冻结加入已有 Agent。
若安装这些功能同时要求理解经营行动、来源系统、数据库和模型调度，接入成本会超过组件本身的价值。

## 决定

Core 保留小接口和零运行依赖。业务验证通过回调接入；JSON Schema 通过示例组合 Ajv。
图拓扑、角色披露、模型调用检查点、文件锁和企业行动合同留在高级群体场景。
从高级系统提炼能力前，先冻结测试输入，验证输出、失败状态及调用次数。

## 结果

用户可以只使用一个组件；宿主必须提供业务规则、调度和持久化。
Core 不提供通用队列或框架适配器，完整场景也不能代表安装 Core 自动获得其全部能力。
接口扩展依据可复现的重复需求，而不是按场景功能数量增长。
