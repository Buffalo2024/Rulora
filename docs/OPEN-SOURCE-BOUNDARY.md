# Open-source boundary

## Included

- Hybird 机制与架构说明；
- 通用字段分支状态机；
- Token、无进展和人工接管门禁；
- Repository、Provider、Channel 与 Quality Gate 接口模式；
- 三个虚构、去商业化、可运行案例；
- 测试、审计与发布安全规则。

## Commercial applications

作者另有基于以上三个场景案例及 Hybird 机制开发的商业化应用。商业应用的产品实现、业务
配置、运营数据和实际交付内容不属于本仓库的开源范围。是否开放某项内容，以它是否真实提交
在本仓库并受到仓库许可证覆盖为准。

真实用户数据、支付或客服记录、生产 API 配置，以及未经授权的第三方素材，无论是否用于
商业应用，都不应提交到本仓库。
