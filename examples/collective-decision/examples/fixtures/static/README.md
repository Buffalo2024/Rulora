# 不运行也能阅读的合成样例

- [完整输入](example-input.json)：企业、日期、两条证据与快照引用。
- [预期输出](example-output.json)：首次脚本模型调用次数、重放次数和完整最终报告。
- [检查点](example-checkpoint.json)：真实运行生成的一份需求与增长席检查点，含输入身份、哈希和校验后输出。
- [快照载体](example-snapshots.json)：仅用于测试的文本；不会下载网址。

以上均为虚构测试数据。证据 URL 是协议占位，不代表该机构发布了这些内容。
检查点时间已固定为展示值，其输入与输出哈希保持有效。
输入中的 `evidence_snapshot_root: "snapshots"` 由离线驱动解析到临时目录；
真实 CLI 输入需要指定用户自己的快照目录，并提供经核验的来源和文件。

在群体决策目录执行 `npm run example:static`：程序物化快照、验证哈希、
运行完整系统并比较预期报告，再重放，最后从独立目录复用预置检查点。
运行产物仅在临时目录中，结束后清理。
快照或协议发生变化，应重新生成并审阅样例；不能修改预期结果来掩盖失败。
