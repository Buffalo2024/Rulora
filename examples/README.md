# Rulora 场景案例

三个案例展示同一套 Hybrid 机制在不同任务中的落地方式。

| 案例 | 适合学习 | 确定性交付 |
|---|---|---|
| [01 · 受控诊断 Agent](01-guided-diagnosis/README.md) | 多轮对话、分支 Loop、证据与冻结 | 程序决定字段和流程状态 |
| [02 · 原生报告生图](02-native-image-report/README.md) | 结构化报告到图片任务 | Mock 流程演示基础检查和 QA 顺序 |
| [03 · 稳定生图复刻](03-stable-image-reproduction/README.md) | 满载设计、槽位冻结与批量复刻 | 实际检查字符容量，Mock 融合与像素结果 |

示例使用虚构信息和 Mock Provider。图片案例不会生成真实图片或执行 OCR。
