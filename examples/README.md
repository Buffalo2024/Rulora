# Rulora 场景案例

三个案例展示同一套 Hybird 机制在不同任务中的落地方式。

| 案例 | 适合学习 | 确定性交付 |
|---|---|---|
| [01 · 受控诊断 Agent](01-guided-diagnosis/README.md) | 多轮对话、分支 Loop、证据与冻结 | 程序决定字段和流程状态 |
| [02 · 原生报告生图](02-native-image-report/README.md) | 结构化报告到原生图文生成 | 程序检查内容、OCR、视觉和重试 |
| [03 · 稳定生图复刻](03-stable-image-reproduction/README.md) | 满载设计、槽位冻结与批量复刻 | 程序控制容量、排版和像素边界 |

示例使用虚构信息和 Mock Provider。作者另有基于这些机制开发的商业化应用，商业应用本身
不属于本仓库的开源内容。
