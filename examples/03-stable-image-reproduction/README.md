# Case 03 · 稳定生图复刻

[English](README_EN.md) · [运行示例](run.js)

## 一句话定位

让图片模型完成第一次“满载内容设计”，再由程序冻结槽位并稳定复刻短文字版本。

## 适合什么场景

- 文字较短、结构稳定、需要批量保持版式一致；
- 设计已经通过图文协同确认，后续变化仅发生在注册槽位内；
- 要求溢出即拒绝、槽位外像素不变和机器可审计。

## Hybird 分工

| 模型负责 | 程序负责 |
|---|---|
| 使用满载模拟文案完成初版图文设计 | 识别并冻结动态槽位、容量、字体与边界 |
| 按每个槽位容量压缩候选文案 | 确定性文字融合与溢出拒绝 |
| 必要时帮助修正初始设计 | 验证槽位外像素不变并保存 QA 报告 |

## 标准流程

```text
满载模拟内容 → 图片模型原生设计 → 确认设计
→ 槽位注册 → 新 JSON → 容量校验 → 确定性融合 → 像素检查
```

```bash
npm run example:stable-image
```

它适合短文字复刻，不替代案例二的高密度原生报告生成。如果运行期完全没有模型理解或
内容压缩，它只是确定性模板渲染器，而不是完整 Hybird 场景。
